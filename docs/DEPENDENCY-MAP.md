# DEPENDENCY MAP -- the Windows layer the port converts FROM

Generated by `depmap.py` (static) + `relay_scan.py` (runtime, Wine `+relay`).

## Why this file exists

The port had a **surface census** (how many sites mention a symbol) but no
**dependency graph** (who calls what, in what order, and what stops without it).
So the shim was being built in *compiler-error order*. These are the same numbers
re-derived as a graph, plus the runtime order measured from Wine -- which is the
reference implementation of exactly the layer being replaced.
